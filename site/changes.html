Product change log

Current MVP

Source-selected trial finder

Users can search by condition, city/postcode, radius, status, and source selection. Results prioritize nearest listed site, distance, site status, trial status, and official registry link.

AI layer

Source-grounded AI Research Radar

Trial-level AI reading aids summarize public registry fields, surface verification points, and generate neutral clinician discussion questions.

Deployment

Docker and health checks

The project includes Docker, compose, runtime environment variables, API rate limiting, cache TTL cleanup, and /health for deploy checks.

Next

Empty-result guidance and second connector

The next useful improvements are better no-result recovery, AI guided search parsing, and the first non-ClinicalTrials.gov connector.

Weekly public-data reports

Generated weekly reports and full registry snapshots are not committed to the public source tree. They should be generated locally or published as deployment artifacts after source review.

Local command pattern: run the finder or radar scripts, review generated public-data outputs, then publish only the artifacts you intentionally want to share.
