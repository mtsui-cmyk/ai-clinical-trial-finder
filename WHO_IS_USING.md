# Who Is Using TrialCompass

TrialCompass does not include default telemetry or call-home tracking. If you deploy or adapt this project, you are welcome to add your public deployment here by opening an issue or pull request.

Please include only public, non-sensitive information. Do not include patient data, search logs, private location data, personal medical information, or recruitment leads.

## Public Deployments

No public deployments have been submitted yet.

## How To Add Yours

Open an issue or pull request with:

- Organization or project name
- Public deployment URL, if available
- Region or audience, if you want to share it
- Data sources enabled
- Short note about how you are using the tool

Example:

```text
- Example Patient NGO
  - URL: https://example.org/trialcompass
  - Region: EU patient education
  - Sources: ClinicalTrials.gov
  - Notes: Used as a public registry search and plain-language reading aid.
```

This list is for transparency and collaboration only. It is not an endorsement, medical recommendation, or verification of any deployment.
