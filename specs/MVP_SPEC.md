# MVP_SPEC.md

## MVP Name

Open Disease Research Radar

Possible first implementation:

- Open Lupus Research Radar

## Target Users

- Patients and caregivers trying to understand the public research landscape
- NGO and patient advocacy groups
- Researchers and volunteers who want reusable public datasets
- Developers who want a disease-scoped clinical trial data pipeline

## MVP Outputs

- Normalized trial JSON
- Trial CSV
- Intervention list
- Sponsor list
- Country summary
- Weekly Markdown report
- README dashboard
- Safety and methodology docs

## MVP Data Source

- ClinicalTrials.gov API v2 only

## MVP AI Features

- Plain-language trial summary
- Weekly public-data briefing
- Research terminology explanation
- Intervention category assistance

## Explicitly Out of Scope

- Patient matching
- Eligibility determination
- Drug/device recommendation
- Treatment ranking
- Personal medical data intake
- Paid patient lead generation
