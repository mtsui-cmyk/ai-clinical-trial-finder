# SAFETY.md

## Project Safety Boundary

This project organizes and explains public clinical research information. It does not provide medical advice.

## This Project Does Not

- Determine whether a patient is eligible for a trial
- Recommend any trial, drug, device, or therapy
- Rank therapies by safety or effectiveness
- Interpret personal medical records or lab results
- Diagnose conditions
- Recommend treatment changes
- Collect patient health information

## This Project Does

- Organize public clinical trial registry data
- Track public changes in trial records
- Explain trial terminology in plain language
- Produce transparent source-linked summaries
- Help users prepare questions for licensed clinicians

## AI Use Rules

AI may summarize, simplify, classify, and translate public registry text.

AI must not infer individual suitability, treatment value, clinical benefit, or medical risk beyond what the source explicitly states.

All AI-generated text should preserve source links and include a clear non-medical-advice boundary.
